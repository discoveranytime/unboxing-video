# How to Film an Unboxing Video Correctly — Sealed Box to Empty Box — Interactive Infographic

Live site: https://discoveranytime.github.io/unboxing-video/

An interactive educational infographic teaching how to film a parcel unboxing
correctly: setup, filming the sealed package, the continuous take, item-by-item
documentation, quantity checks, damage evidence, reporting problems, keeping the
original file, and common mistakes.
